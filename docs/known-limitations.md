# Known Limitations (MVP)

## Performance
- **Image Processing**: High-resolution videos might take 5-10 seconds to analyze.
- **Real-time Sync**: Search results might have a 1-2 minute delay for brand new listings due to indexing.

## Features
- **Payment Processing**: Currently using mock checkout flow; no real credit card processing.
- **Messaging**: Chat is powered by AI Assistant; direct Seller-to-Buyer messaging is limited in this preview.
- **Categories**: Only Electronics, Fashion, Home, and Automotive are fully supported by the AI classifier.

## Mobile
- **Video Capture**: Native camera integration varies by mobile browser. Chrome on Android is recommended.
